# Prerequisite
- [Autohotkey V2](https://www.autohotkey.com/)
- [OCR library](https://github.com/Descolada/OCR) (Installed in the Autohotkey/Lib folder)

# Installation
- Clone the repo, download individual scripts, or simply copy paste functions you need into a `.ahk` file
- Double click on them to launch them and try them out

## Launching a script on startup
- Right click the script you want, select "Create a shortcut"
- "Cut" the shortcut (Ctrl-X or Right click -> Cut)
- Press `Win+R`
- type `shell:startup`
- Paste the shortcut in the folder
